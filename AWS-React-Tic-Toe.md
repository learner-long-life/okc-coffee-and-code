## Tutorial 

### Step 0: Pair Programming

We'll be practicing *pair programming* today, a development technique (and furniture arrangement)
that lets two programmers sit side-by-side at the same computer, working on the same piece of code.

You can think about it as your ideal virtual road trip of learning and coding together,
where the destination will be a piece of software at the end that you co-created together.

One programmer types and clicks the mouse, and is known as the *driver*. 
The other programmer helps read documentation, look things up on the internet

You can read more about [pair programming here by some of its original practitioners](https://martinfowler.com/articles/on-pair-programming.html).

### Step 4: React 

React is a web component framework for front-end that emphasizes reusability and modularity. You can think of it as letting you
define custom HTML tags, which also come complete with their own local CSS styling and JS interactivity. Those tags can have 
their *own* child tags, and so on. It pioneered the JSX (JavaScript Extended) format that lets you combine 
HTML (document structure), CSS (styling), and JS (structure) at multiple levels of hierarchy, letting you fit it to your
app idea or use case.

We'll be following the [official React Tic-Tac-Toe tutorial here](https://react.dev/learn/tutorial-tic-tac-toe).
